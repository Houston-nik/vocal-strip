# Минусовка

Простая программа: кидаешь песню — получаешь **оригинальную фонограмму без ведущего вокала**. Музыку программа не сочиняет заново, а вынимает голос из твоего файла.

## Как запустить у себя

Нужны три вещи, как кухонных прибора:

1. **Python 3.10+**
2. **Node.js 20+**
3. **ffmpeg** (это «открывалка» для MP3)

На Ubuntu:

```bash
sudo apt install ffmpeg python3 python3-venv
```

На Mac:

```bash
brew install ffmpeg
```

Потом в папке проекта:

```bash
chmod +x start.sh
./start.sh
```

Открой в браузере адрес, который напишет программа — обычно `http://127.0.0.1:43147`.

Первый запуск ставит библиотеки и может скачать нейросеть (~70 МБ). Это один раз.

## Какой режим нажимать

- **Классическая минусовка** — убирает весь вокал. Это обычная минусовка для караоке.
- **Только солист** — срезает главного певца, бэк-вокал часто остаётся.
- **Быстрый черновик** — без нейросети, за несколько секунд. Работает хуже, но всегда под рукой.

Точные режимы думают минуту-другую на обычном компьютере. Это нормально: программа реально слушает спектр песни, а не «магически» выключает микрофон.

## Если нет окна, а есть только терминал

```bash
source .venv/bin/activate
python -m engine путь/к/песне.mp3 -m classic
```

Рядом появится файл `…-minusovka.wav` и MP3.

## Что лучше закидывать

Студийные стерео-треки. Живые концерты, моно и песни с огромным эхом даются труднее.

Делай минусовки из своих записей или треков, на которые у тебя есть право.
